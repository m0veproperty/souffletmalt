# Soufflet Malt static mirror

Static repository mirror of the captured Soufflet Malt homepage experience.

The project keeps the preloader, GSAP scroll animation, Three.js scene, GLB models, audio, video, SVG artwork, images, fonts and page JavaScript in repository paths so the deployed experience does not depend on the original site for its core visual and interactive assets.

Deploy the repository root as a static site. No build command is required.
